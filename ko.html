ROADVISION CAMERA CALIBRATION

자동 정사영 변환 방식
검토 및 개선 요청

기존 4개 정사영 파라미터 방식과 현재 자동 교정 방식의 차이를 확인하고, 차량 회전 왜곡을 방지하기 위한 변환영역 제약과 UI 개선 방향을 제안한다.

검토 대상: Front Camera BEV기준 출력: 1224 × 1024핵심 이슈: 6-parameter vs 8-parameter

1. 핵심 요약

기존 입력은 4개

yaw, pitch, width, length를 사용한다.

기존 행렬은 6개 값 계산

수평 사다리꼴 제약으로 h21, h31이 0이다.

현재 자동 방식은 8개 행렬 값 계산

사용자가 선택한 임의 사각형을 그대로 사용한다.

자동 방식도 기존 구조 유지 필요

변환영역의 위·아래 변을 x축과 평행하게 제한한다.

사다리꼴 유지 UI 필요

네 점을 이동할 때 수평 제약을 어떻게 적용할지 결정해야 한다.

BEV 영상 세로축

차량과 교정판을 기준에 맞게 설치한 상태라면 변환 결과에서도 차량이 좌우로 회전하지 않고 세로축과 정렬되어야 한다.

  • 교정판 크기: 2 m × 2 m
  • 카메라와 교정판 거리: 5 m
  • 변환 결과 교정판: 240 px × 240 px
  • 교정판 위치: ROI 하단 중앙

4개 파라미터 방식의 장점

  • 출력 영상의 불필요한 회전 왜곡 방지
  • yaw, pitch, width, length의 의미가 직관적
  • 기존 저장 구조 및 역변환 계산과 호환
  • 현장 작업자가 결과를 이해하고 미세 조정하기 쉬움

4. 현재 자동 정사영 변환의 차이

현재 자동 행렬 
H =
[-0.357376940  -0.905386407  1007.356816135]
[-0.020639505  -1.892168148  1784.690500771]
[-0.000068654  -0.001458344     1.000000000]

원인

현재 프로그램은 사용자가 지정한 네 점을 독립적인 임의 사각형으로 사용한다. 윗변과 아랫변의 y값이 서로 달라질 수 있으므로 일반적인 8-파라미터 원근변환 행렬이 생성된다.

h21과 h31이 0이 아니며, 작은 선택 오차나 사각형의 기울기가 영상 전체의 회전 왜곡으로 반영될 수 있다.

판정: 교정 기준대로 차량과 교정판을 평행하게 설치했음에도 BEV에서 차량 중심축이 세로축과 일치하지 않으므로, 현재 자동 교정 결과는 원하는 기존 정사영 결과와 호환되지 않는다.

5. 요구되는 자동 정사영 변환

사용자가 네 점을 선택하더라도 실제 변환영역은 수평 사다리꼴을 유지해야 한다.

윗변의 두 점은 동일한 y값을, 아랫변의 두 점도 동일한 y값을 갖도록 제한한다. 보정된 네 점으로 변환행렬을 다시 계산하면 기존과 동일한 6-파라미터 구조를 유지할 수 있다.

요구 행렬 
[ h11  h12  h13 ]
[  0   h22  h23 ]
[  0   h32   1  ]

검증 조건

abs(h21) < epsilon
abs(h31) < epsilon

부동소수점 계산 오차가 있으므로 정확한 0 비교 대신 허용오차를 사용한다. 행렬 계산 후 값을 강제로 0으로 바꾸지 말고, 입력 사다리꼴을 먼저 보정한 후 행렬을 계산해야 한다.

6. 사다리꼴 유지 UI 방안

방안동작장점검토사항
A. 점 이동 연동 위쪽 점 하나를 세로로 이동하면 반대쪽 위 점의 y값도 함께 변경한다. 아래쪽도 동일하다. 현재 4점 UI를 유지하면서 구현 가능 사용자가 연동 동작을 쉽게 인지할 수 있어야 함
B. 선택 후 자동 보정 사용자가 네 점을 자유롭게 선택하면 위·아래 점의 y값을 각각 평균하여 수평 사다리꼴로 변환한다. 초기 클릭 오차를 자동 흡수 원시 선택점과 보정점을 구분해 표시할 필요가 있음
권장안: B 방식으로 최초 네 점을 수평 사다리꼴로 자동 보정하고, 이후에는 A 방식으로 점 이동을 연동한다. 실제 변환에 사용하는 사다리꼴은 굵은 선으로 표시하고 사용자가 최초 선택한 점은 보조 표시로 구분한다.

7. 수정 요구사항

윗변 두 점의 y좌표가 동일하고, 아랫변 두 점의 y좌표가 동일해야 한다.
점 이동 후에도 수평 사다리꼴 제약이 항상 유지되어야 한다.
계산된 행렬에서 h21≈0, h31≈0을 만족해야 한다.
기존 역변환을 통해 yaw, pitch, width, length를 생성할 수 있어야 한다.
BEV 결과에서 차량 중심축, 교정판 세로축, 영상 세로축이 일치해야 한다.
교정판은 ROI 하단 중앙에서 240 px × 240 px 정사각형으로 표시되어야 한다.

8. 당사 검토 의견 및 제안

일반적인 3×3 호모그래피 행렬이 8자유도를 가지며, 임의의 8자유도 행렬을 기존 4개 파라미터로 정확하게 환산하기 어렵다는 개발사의 설명에는 동의한다. 그러나 당사는 이를 해결하기 위해 기존 4개 정사영 파라미터를 없애고, 기존 소프트웨어에서 3×3 행렬을 직접 입력받도록 변경할 필요는 없다고 판단한다.

4개 파라미터를 유지해야 하는 이유

  • yaw, pitch, width, length의 의미가 직관적이다.
  • 현장에서 교정값의 이상 여부를 확인하고 필요시 미세 조정할 수 있다.
  • 기존 장비, 설정 파일, 역변환 계산 및 운영 절차와 호환된다.
  • 차량과 교정판을 평행하게 배치하는 물리적 교정 조건을 반영한다.
  • 불필요한 회전 자유도를 제한하여 차량의 회전 왜곡을 방지한다.

행렬 직접 입력 방식의 우려사항

  • 행렬 각 값의 의미와 정상 범위를 현장 작업자가 판단하기 어렵다.
  • 사용자가 선택한 모서리점의 오차와 기울기가 결과 전체에 반영될 수 있다.
  • 차량이 회전된 결과도 수학적으로 유효한 행렬로 처리될 수 있다.
  • 기존 소프트웨어와 데이터 구조를 변경해야 한다.
  • 차량별 교정값을 직관적으로 비교하고 관리하기 어렵다.

당사 제안

현재의 괴리는 기존 4개 파라미터의 문제가 아니라, 자동 교정 프로그램이 기존 모델에 없는 자유도까지 포함한 임의의 8자유도 행렬을 생성하기 때문에 발생한다.

따라서 기존 프로그램을 전체 행렬 입력 방식으로 변경하기보다, 자동 교정 단계에서 사용자가 선택한 네 점을 수평 사다리꼴로 보정하고 기존 구조와 호환되는 변환행렬 및 4개 파라미터를 생성하는 방향으로 수정할 것을 제안한다.

기존 시스템을 8자유도 행렬에 맞추는 것이 아니라,
자동 교정 결과를 기존 4개 파라미터 교정 모델에 맞춘다.
최종 요청: 8자유도 행렬을 계산한 후 4개 파라미터로 근사하거나 수동으로 다시 조정하는 방식이 아니라, 최초 네 점 선택 단계부터 기존 모델의 제약조건을 적용하여 4개 파라미터와 호환되는 결과를 직접 생성해 주기 바란다.
